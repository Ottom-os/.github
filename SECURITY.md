# Security Policy

## Reporting a vulnerability

**Do not open a public issue.**

Email the maintainer privately or use GitHub's private vulnerability reporting on the affected repo. Include:

- Affected repo + commit SHA
- Reproduction steps or PoC
- Your assessment of impact (confidentiality / integrity / availability)
- Whether you've disclosed to anyone else

We acknowledge within 48 hours. We aim for a fix or mitigation plan within 7 days for critical issues.

## Scope

In scope:
- Any repo under `Ottom-os`
- The Skill Foundry Proof Object schema and signature verification
- Auth/credential handling in any Ottom-OS code

Out of scope:
- Vulnerabilities in upstream dependencies (report those upstream; we'll track)
- Social engineering against maintainers
- Denial-of-service against public infrastructure we don't own

## Disclosure

We follow coordinated disclosure. We will credit reporters in the fix commit + release notes unless you ask otherwise.

Validated security reports earn **+10 Foundry reputation**.
