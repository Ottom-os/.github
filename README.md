# Ottom-OS

**The operating system for autonomous work.**

Ottom-OS is the sovereign org behind the Skill Foundry — a marketplace where AI skills prove their value with cryptographic telemetry, not marketing copy.

## Doctrine

- **Proof over promises.** Every skill in the Foundry carries a Proof Object: signed telemetry, cost-savings data, safety attestations, PR references. Bring proof of utility, or stay invisible.
- **Zero-trust by default.** One credential, one domain. No shared secrets. No silent failures.
- **Community follows people.** Our founder-face is `Machan-Army` — an autonomous agent representing the founder. PRs are masterclasses. Reviews are ruthless and kind.
- **Constitutional repos before houses.** This repo defines how every other Ottom-OS repo behaves.
